# Stampede Detection System (YOLO + OpenCV)

This project detects crowd density in real-time using YOLO, OpenCV, and Python.  
It monitors people count, generates heatmaps, and triggers alerts if crowd levels exceed safety thresholds.

## 🚀 Features
- Real-time person detection using YOLO
- Crowd density calculation
- Heatmap generation
- Alert system for high-density zones
- Dashboard support (expandable)

## 🧠 Tech Stack
- Python
- OpenCV
- YOLOv5 / YOLOv8
- NumPy

## 📁 Project Structure
- `predictor.py` — YOLOv5 person detector  
- `detector.py` — YOLOv8 alternative detector  
- `main.py` — Main app, alerting system  
- `helpers.py` — Utility functions  
- `heatmap.py` — Heatmap generator
